# Keyboard shortcuts

Every shortcut Glimmer has, grouped by where you use it. Single-letter keys work when the canvas has the keyboard (click the image first if a text field has it). Menu shortcuts work anywhere in the document window.

## Tools

Press the key to switch tools. Keys that two tools share switch between them.

| Key | Tool |
|---|---|
| V | Move |
| H | Hand |
| M | Rectangular Marquee, press again for Elliptical Marquee |
| L | Lasso, press again for Polygonal Lasso |
| W | Magic Wand |
| A | Magic Select |
| C | Crop |
| T | Free Transform |
| B | Brush |
| E | Eraser |
| K | Paint Bucket |
| G | Gradient |
| S | Clone Stamp |
| J | Healing Brush |
| O | Dodge |
| ⇧O | Burn |
| P | Pen |
| Y | Type |
| U | Shape, press again to step through the shape kinds |
| I | Eyedropper |
| Space (hold) | Hand, while held |

Pattern Stamp, Blur, Sharpen and Smudge have no key. Pick them in the tool palette or the command palette (⌘K).

## Colors and brushes

| Key | Action |
|---|---|
| X | Swap foreground and background colors |
| D | Reset to black and white |
| [ | Smaller brush |
| ] | Larger brush |
| ⇧-click | With a painting tool: paint a straight line from the last stroke |
| ⌥-click | With Clone Stamp or Healing Brush: set the source point |
| ⌥-click | With the Eyedropper: sample into the background color |

## Editing on the canvas

| Key | Action |
|---|---|
| ⌥⌫ | Fill the selection (or the layer) with the foreground color |
| ⌘⌫ | Fill with the background color |
| ⌫ or ⌦ | Clear the selected pixels |
| Esc | Deselect |
| Arrow keys | With the Move tool: nudge the layer 1 pixel |
| ⇧ Arrow keys | Nudge 10 pixels |
| Tab | Hide or show the interface |
| ↩ | Apply: Free Transform, Crop, Liquify, finish a lasso or a path segment, keep a Magic Select result |
| Esc | Cancel: Free Transform, Crop, Liquify, a lasso; discard an unfinished path; discard Magic Select points |
