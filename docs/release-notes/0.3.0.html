Smarter, on your Mac

  • Auto Enhance (⇧⌘L) and Auto Color (⇧⌘B) add editable adjustment layers.
  • Auto Straighten levels a tilted horizon; Suggest Crop frames the subject, including faces.
  • Select People and Select Sky; Straighten Document flattens a page or sign shot at an angle.
  • Image Text to Layers turns the words in a photo into editable text layers.
  • The omnibar suggests what the open photo needs.

Workflow

  • File › Batch Process… edits whole folders and rates photos, flagging blurry shots.
  • Export for Web with a longest side and a file-size limit.
  • AI agents can drive Glimmer through a local API: see Help › Agent Access.
  • The AI service and the model download source can be changed in Settings.
