Models are downloaded only when you say so, and checked

  • Glimmer 0.3.0 downloaded the models for Select Sky, Magic Select and Lens Blur without a fixed version and without checking any checksum. 0.3.1 corrects that.
  • Glimmer now fetches each model at a fixed version and checks every file against the checksum its source publishes. A model whose checksum doesn't match is not installed.
  • Nothing is downloaded until you click Download. The first time a feature needs a model, Glimmer shows its size, publisher, source and license. Settings › Models has a Download… button for each model.
  • A model that 0.3.0 downloaded is checked if its downloaded files are still on your Mac. Otherwise Settings › Models shows it as “Unverified (installed by an earlier version)”. It keeps working, and Download Again replaces it with a checked copy.

New default AI models

  • Google has retired both earlier defaults: gemini-3-pro-image-preview was shut down on June 25, 2026, and from December 1, 2026 gemini-2.5-flash is sent on to gemini-3.5-flash-lite (Google's deprecations page, read November 19, 2026).
  • The defaults are now google/gemini-3-pro-image for pictures and google/gemini-3.5-flash for the Assistant, which passed the Assistant's evaluation as well as before.
  • If you chose one of the old models yourself, Glimmer keeps your choice and says under the field what Google does with it. Restore Defaults switches.

For agents

  • The agent guide has a new section, “What Glimmer may need installed”, and GET /api/v1/requirements lists it as JSON: source, version, checksums, license, size, and how each item is installed and checked.
  • POST /api/v1/settings/open opens a Settings pane for the person and changes nothing.
  • A step that needs a model that isn't downloaded is refused before anything runs, with model_missing and the item it needs. The API never starts a download.
